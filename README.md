Entry for the make.fun bounty [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d): a program that writes the one line a smart fridge texts its owner at 3am. The fridge has been counting the owner's late-night visits — and it has snitched to the fitness app.

## The line (96 chars)

> 3:04am, visit number 7, and your fitness app just replied to my report: 'We know. He's blocked.'

## Run

```sh
python3 -P -s main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`): one line, 96 chars, no trailing newline.
